# Rolling in the Dough — Agent Guide

Sweepstakes slot machine. React 19 + Vite + Wouter + Radix UI + Tailwind 4 (client), Express + tRPC (server), Drizzle ORM → Supabase Postgres. 2030 Horizon theme (neo-luxe, glassmorphism, dark void/plasma gold).

## Commands

| Command | What |
|---|---|
| `pnpm dev` | `NODE_ENV=development tsx watch server/_core/index.ts` (port auto-finds from 3000) |
| `pnpm build` | `vite build` (→ `dist/public/`) + `esbuild server/_core/index.ts` → `dist/index.js` |
| `pnpm start` | `NODE_ENV=production node dist/index.js` — needs `pnpm build` first |
| `pnpm check` | `tsc --noEmit` |
| `pnpm format` | `prettier --write .` (semi, trailingComma es5, arrowParens avoid) |
| `pnpm test` | `vitest run` (env: node, no jsdom) |
| `pnpm db:push` | `drizzle-kit generate && drizzle-kit migrate` — needs `DATABASE_URL` in env |
| `node server/seed-packages.pg.mjs` | Seed coin shop packages into DB |

## Architecture

- **Server entry**: `server/_core/index.ts` — Express + security middleware + tRPC at `/api/trpc`. `/api/oauth/callback` via separate routes. `server/index.ts` is a legacy static-only entry (not built or used).
- **tRPC router**: `server/routers.ts` — `publicProcedure`, `protectedProcedure` (requires auth/session), `adminProcedure`. Sub-routers: `auth`, `shop`, `game`, `cashout`, `referral`.
- **Auth**: Two paths — Supabase OAuth (Google) via `client/src/const.ts:getOAuthUrl`, and email/password via bcrypt. Both set a 30-min session cookie (`app_session_id`). Lockout after 5 failed attempts (15 min).
- **Client entry**: `client/src/main.tsx` — tRPC + React Query. Auto-redirects to `/api/oauth/authorize?provider=google` on `UNAUTHORIZED` errors (message: `'Please login (10001)'`).
- **Routes** (wouter in `App.tsx`): `/`, `/checkout-success`, `/pricing`, `/terms`, `/privacy`.
- **Dual currency**: `goldCoins` (free play, no cash value) + `greenCoins` (premium, cash-out eligible at 100 coins = $1).
- **Payments**: Square Checkout API (redirect) + Coinbase Commerce (crypto). No Stripe.
- **Path aliases**: `@/` → `client/src/`, `@shared/` → `shared/`, `@assets` → `attached_assets/`.
- **DB is lazy** (`server/db.ts`): `getDb()` returns `null` if no `DATABASE_URL` — safe to run without one.
- **Shared types**: `shared/types.ts` re-exports `drizzle/schema` types + `shared/_core/errors`.
- **`_core/` modules**: Both `server/_core/` and `client/src/_core/` contain framework wiring (context, security, oauth, trpc, audio engine, auth hook).
- **Vite root**: `client/` directory, not project root. Allowed hosts include `.manus` domains.

## Testing

- `vitest run` — tests colocated: `server/**/*.test.ts`, `client/**/*.test.ts`.
- Test env is **node** (not jsdom). Client tests must be pure logic or mock DOM. See `server/auth.logout.test.ts` for inline-mock tRPC caller pattern.

## Key gotchas

- **Dockerfile** nested path `lucky-spins-source/lucky-spins-source/` (legacy artifact).
- **`wouter@3.7.1`** patched in `patches/wouter@3.7.1.patch`. Actual dep is `"wouter": "^3.3.5"`.
- **`tailwindcss>nanoid`** overridden to `3.3.7` via pnpm overrides.
- **pnpm** must match `10.4.1` (listed in packageManager) — lockfile format varies by version.
- **Dev port** auto-increments from 3000 if busy (logs actual port).
- **Server-authoritative RNG** — spin outcomes generated by `crypto.randomInt()` in `server/game.ts`, fetched via `trpc.game.spin`. Client `useGameState.ts` calls server instead of `Math.random()`.
- **Loss-disguised-as-win**: ~35% of losing spins show fake win visuals (`useGameState.ts:163-172`).
- **Starting coins**: 10,000 set in `useGameState.ts:16` (testing default).
- **Server body limit**: 50mb (file uploads).
- **Health endpoint**: `/health` (skips rate limiting, referenced by `render.yaml`).
- **Security**: helmet headers, CSRF tokens, rate limiters (general 100/15min, login 5/15min, payments 10/hr, spins 60/min).
- **Render deploy** via `render.yaml` uses `npm install` / `npm start` (not pnpm).
- **`.env`** contains real Supabase/DB credentials — already gitignored, handle with care.
- **Vite plugins**: `vite-plugin-manus-runtime` and inline Manus debug collector (writes browser logs to `.manus-logs/`).
- **Supabase project**: `https://fla0t0f0c1lo5mgtbqj.supabase.co` (from `render.yaml`).
- **BET_OPTIONS**: `[10, 25, 50, 100, 200]` in `shared/game.ts:58`.
